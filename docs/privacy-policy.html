Privacy Policy — Full Page Screenshot

Last updated: 2026-08-23

English

Data collection

This extension does not collect, store, or transmit any personal data or browsing information to external servers. There is no analytics, no tracking, and no third-party service of any kind.

What the extension does

  • Captures screenshots of the page you explicitly ask it to capture
  • Stores that screenshot temporarily in local browser storage so the editor tab can open it
  • Downloads the image to your device when you press Save
  • Copies the image to your clipboard when you press Copy

Permissions

  • activeTab — grants access to a single tab, only after you explicitly start a capture (toolbar button, keyboard shortcut, or right-click menu). The access ends when that tab navigates.
  • scripting — used to measure and scroll the page being captured, to hide fixed headers so they are not repeated in every stitched section, and to show the drag-to-select overlay. Code is injected only into the tab you are capturing.
  • downloads — saves the finished screenshot to your device.
  • storage / unlimitedStorage — stores your preferences and passes the captured image to the editor tab. Full-page screenshots regularly exceed the default 10 MB quota, which is why unlimited storage is requested.
  • alarms — implements the 3 / 5 / 10 second delayed capture.
  • contextMenus — adds the two right-click menu entries.
The extension requests no host permissions. It has no standing access to the sites you visit and cannot read or capture any page you have not explicitly asked it to.

Data storage

Everything is processed locally on your device using Chrome's storage API. No data is sent to any server.

Contact

Questions about this policy: please open an issue on the project's GitHub repository.

日本語

データ収集について

この拡張機能は、個人データや閲覧情報を外部サーバーに収集・保存・送信することは一切ありません。 アナリティクス、トラッキング、サードパーティサービスも一切使用していません。

拡張機能の動作

  • あなたが明示的に指示したページのスクリーンショットを撮影します
  • 編集画面で開くために、その画像をブラウザのローカルストレージに一時保存します
  • 「保存」を押したときにデバイスへダウンロードします
  • 「コピー」を押したときにクリップボードへコピーします

使用する権限

  • activeTab — あなたがキャプチャを開始した時（アイコンクリック・ショートカット・ 右クリックメニュー）にのみ、そのタブ1つへのアクセスが付与されます。タブが遷移すると失効します。
  • scripting — キャプチャ対象ページの計測・スクロール、固定ヘッダーの一時非表示、 範囲選択オーバーレイの表示に使用します。注入先はキャプチャ対象のタブのみです。
  • downloads — スクリーンショットをデバイスに保存します。
  • storage / unlimitedStorage — 設定の保存と、撮影した画像を編集画面へ 受け渡すために使用します。フルページの画像は標準の10MB制限を超えることが多いため、 無制限ストレージを要求しています。
  • alarms — 3 / 5 / 10 秒の遅延キャプチャに使用します。
  • contextMenus — 右クリックメニューの2項目を追加します。
この拡張機能は host permissions（ホスト権限）を一切要求しません。 閲覧中のサイトへの常時アクセス権はなく、あなたが明示的に指示していないページを読み取ることはできません。

データの保存

すべての処理はChromeのストレージAPIを使い、お使いのデバイス上でローカルに完結します。 外部サーバーへの送信は一切ありません。
